# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-09

### Added

- Upload and sharing of images, including support for Apple iPhone HEIC image files.
- Automatic scanning of uploaded images for potential manipulation.
- Secure storage of images in Object Storage.
- Gallery for viewing and sharing uploaded images.
- Download functionality for shared images.
- Administration console for managing the application.
- Built-in customization options available out of the box.
- Simple and fast installation and configuration (Docker).
- Easy maintenance and administration.
- Modern and responsive user interface.

### Changed

- Initial application architecture and configuration.
